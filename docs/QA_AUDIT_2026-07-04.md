# Orb QA Audit: 2026-07-04

Full-stack audit: live browser testing of every clinician module plus a multi-agent code review
of the frontend (`src/`) and backend (`server/`). This file records what was **fixed in the
working tree today** and what remains as a **prioritized backlog**.

---

## Session 2: follow-up work (same day)

Delivered in priority order: **Sage timeline → light mode → Bridge → dead buttons.**

### Sage-deduced clinical timeline (replaces the calendar-day rail)
- Root cause of the "43-day timeline for a simple illness": the timeline drew one node per calendar
  day from `admission_date` to today, and the seed (`scripts/reset_db_and_seed.py`) stamps every
  patient's admission to a random moment on **May 21–23** while "today" is **Jul 4**, ~43 days for
  everyone, zero clinical reasoning. The forecast "Est. DC" node used a ward-only heuristic (the LSTM
  ships untrained).
- New: `server/services/timeline_service.py` + `GET /vigil/patients/{id}/timeline-projection`. Sage
  (MedGemma) reasons expected LOS + 3–5 ordered care phases from **diagnosis + comorbidities + age +
  sex**, cached per patient by a hash of those inputs. Current phase is derived from the patient's
  **live risk level** (acute → early phase), so it stays fresh without the calendar. New frontend
  component `src/components/ClinicalCourseTimeline.tsx` renders the phases with the current one
  highlighted, a rationale, and discharge criteria. Verified in both themes.

### Light-mode sweep (all panels)
- Vigil, Sage, Admin fixed directly; Forecast, Surgery, Scribe, Lens, Relay, Appointments, Bridge
  fixed via agents. Hardcoded colors → design tokens / `[data-theme="light"]` overrides. Also fixed a
  real CSS bug: Forecast weekday bars used an invalid `var(--accent-amber)44` alpha append that
  dropped the fill (→ `color-mix`). Snappier panel fade (0.6s→0.3s, shorter stagger). Whole-project
  `tsc` clean.

### Bridge patient portal: new features
- New backend endpoints (`server/routes/bridge_routes.py`): `/care-team`, `/vitals-trends`,
  and real `/appointments` (POST/GET/DELETE, ownership-enforced, `patient_appointment_requests`
  table). New UI: `src/components/bridge/{CareTeamCard,VitalsTrendsCard,AppointmentBookingCard}.tsx`
  + `src/api/bridgeClient.ts`. The **fake `setTimeout` scheduler** (previously the portal's most
  misleading element) is replaced with a real, persisted booking flow. Booking round-trip verified live.

### Dead buttons fixed (audit P0/P1)
- **Surgery AI Risk Assessment** (`SurgicalSuitePanel.tsx`): `loadRiskAssessment` was never invoked, 
  now fires on Tier-3 drill-down; the MedGemma pre-op assessment streams (verified live). Emergency
  banner "Bed undefined" fixed (added `p.bed` to the emergency-queue query).
- **Lens** files the correct analysis: the analyze stream now returns the new `analysis_id`, threaded
  through `client.ts` → `LensPanel`, so "Confirm & File" targets the exact analysis instead of the
  global-newest; object-URL leak fixed.
- **Scribe**: added a patient picker so dictated notes link to an admitted patient (was hardcoded
  `undefined`).
- **Relay**: alert Confirm/Escalate now await + surface errors instead of silent fire-and-forget.
- **Sage** recent-chat click now loads the selected exchange (was dumping the whole history).

### P0/P1 backlog applied
- Discharge tokens now stored/looked-up hashed (raw secret no longer in `audit_logs`); signed-note
  edit/reject race guarded; `scribe.note.signed` event delivery fixed; `message_type` forgery
  restricted; ambient-action / surgery-confirm double-execution claims; ingestion API key timing-safe
  + `/replay` gated + fingerprint UNIQUE index; broken unauth `/auth/me` stub removed; RxNorm corrector
  cached; DB-connection leak try/finally; blocking-call offload; pulse/forecast cache keys; unread-count
  and timestamp-ordering fixes. All changed server files compile; backend healthy.

### Known remaining (not regressions)
- Forecast **Admission Patterns** tab shows zeros because `admission_history` is an empty seed table
  (pre-existing data gap; the main Census forecast is unaffected and shows real data).
- The deeper P0 items that need schema/design decisions (PHI-at-rest encryption, HttpOnly-cookie auth
  + DOMPurify on `dangerouslySetInnerHTML`) remain deferred as documented in the code.

## Part 2: Remaining findings (prioritized backlog, verified but NOT fixed)

### P0: security / clinical safety
1. **Discharge tokens stored & looked up in plaintext**, `discharge_service.py:263`,
   `discharge_access_service.py:58`. `token_hash` column is dead code; the raw bearer secret is the
   PK *and* is written into `audit_logs` as `correlation_id`. Fix: look up by `sha256(presented)`,
   never store/log the raw token. (Schema + audit change.)
2. **Signed notes can be edited/rejected (race)**, `scribe_service.py:659-773`. SELECT-status-then-
   UPDATE without `AND status='draft'` guard; a signed legal record can be silently mutated. Fix:
   conditional UPDATE + rowcount check.
3. **`scribe.note.signed` event never fires**, `scribe_service.py:736`. Sync route → `asyncio.run`
   cancels fire-and-forget tasks before they start; EHR extraction from signed notes is dead.
4. **Message-type forgery**, `models/message.py:13` accepts client-chosen `message_type`; forged
   `ambient_action` cards become executable by any doctor. (post_message membership was fixed today;
   the type allow-list still needs doing.)
5. **Double-execution races on ambient actions / surgery confirm**, `relay_routes.py:249-383`,
   `surgery_escalation_service.py:45-99`. Check-then-act across awaits; duplicate discharges /
   duplicate emergency surgery rows.

### P1: correctness
6. **UTC timestamps rendered as local time** in VigilPanel (notes/timeline day-bucketing),
   PatientShell, AuditLogTable, 5.5h shift in IST; notes after 18:30 land on the previous timeline
   day. RelayPanel's `parseUTC` shows the intended pattern.
7. **Mixed timestamp formats break comparisons/ordering**: sage_actions ordering
   (`sage_proactive_routes.py:60` vs ambient isoformat), admin 24h ingestion window
   (`admin_routes.py:44-64` vs `CURRENT_TIMESTAMP`), `clinical_documents.created_at`.
   Fix: one canonical format (UTC isoformat) at every insert site.
8. **Offline queue replays under next user's identity**, `client.ts` `clearToken` doesn't clear
   `orb_offline_queue`; Dr. A's queued note posts with Dr. B's token.
9. **Patients created via `POST /vigil/patients` never appear on the board**, route creates no
   `admissions` row while the list INNER JOINs active admissions (`vigil_routes.py:48,470`).
10. **GPU coordinator races**, task-name-keyed cancellation cleanup (`gpu_coordinator.py:174`),
    lock released while producer thread still generating (`voice_agent_service.py:488`,
    `scribe_providers.py:316`).
11. **RxNorm index rebuilt from SQLite on every transcription chunk**, `scribe_service.py:210`;
    multi-hundred-ms penalty per 3-5s chunk. Cache the corrector at module level.
12. **LensPanel files wrong analysis** (`analyses[0]` global-latest race) + object-URL leak.
13. **Vigil `/analysis` dedup cache never written** (`vigil_routes.py:302`, `_analysis_cache`
    declared, zero writes), duplicate MedGemma generations, serialized stalls.
14. **Emergency-surgery status races/stuck states**, `_finalize_surgery` overwrites acknowledge;
    CancelledError leaves `emergency_context_generating` forever; emergency queue filter omits
    `emergency_acknowledged` and SELECT omits `p.bed` ("Bed undefined" in banner).
15. **Sage voice/TTS auto-listen chain pinned to first-render closures** (`SagePanel.tsx:257-305`), 
    follow-up utterances lose patient-name hints.
16. **Relay unread counts**, own messages count as unread; user-id substring matching
    (`relay_service.py:22-48`).
17. **Sage room-memory lost-update race** across the ambient LLM await
    (`sage_ambient_service.py:701-739`).
18. **Pulse weather/AQI caches ignore lat/lon** (`pulse_service.py:97,270`), wrong location served
    within TTL.
19. **Forecast**: hospital-flow cache ignores `days` param; admission-pattern stats mislabeled
    30d; Poisson rate biased high (zero-admission days excluded); LLM-failure fallback in Sage
    intent classification defaults to "chart mutation" instead of surfacing "AI unavailable"
    (observed live when the Ollama model 404'd).
20. **Audit hash-chain can fork under concurrent writes** (`audit_service.py:135-164`), later
    verification false-positives as tampering.
21. **DB connection leaks on error paths**, raw `get_db()` without try/finally in
    `voice_agent_service.build_patient_context`, `scribe_routes.reconcile_stale_pending_verifications`,
    several vigil_routes handlers, `sage_service.get_relevant_context` (which also has a
    `query_words` NameError when no admitted patients exist).
22. **Blocking calls on the event loop**, ZMQ send/recv in `scribe_routes.daemon_status` (also
    enqueues a junk `/dev/null` transcription as its "ping"); CfC torch inference called sync in
    `vigil_service.generate_patient_analysis`.
23. **Scribe endpoints use deprecated `require_role`** letting read-only admins author clinical
    drafts, bypassing RBAC audit (`scribe_routes.py:308-530`).
24. **Discharge summary retrieval doesn't re-check token expiry** (only `revoked_at`), 
    `discharge_access_service.py:197-221`.
25. **Ingestion dedup race**, fingerprint check and insert in separate sessions, no UNIQUE index on
    `ingestion_events.fingerprint` → concurrent duplicates double-fire alerts.

### P2: UI/UX polish

30. Duplicate identical Sage suggested-action cards in Relay (dedupe by target+signal at render or

31. Duplicate `.modal-overlay`/`.modal` definitions with conflicting values in `Vigil.css` and

32. Sidebar role text truncates ("Physician · General Me…"); duplicated "CASE ROOMS" section label
